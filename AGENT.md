# Проект: Анализ in situ SAXS/WAXS

## Цель проекта
Разработать воспроизводимый пайплайн для обработки и анализа данных in situ
SAXS/WAXS: загрузка кадров, калибровка, вычитание фона, приведение к
абсолютным единицам, построение кривых I(q) и их эволюции во времени.
Результат — набор скриптов и графиков, пригодных для отчёта или статьи.

## Данные
Даннные с синхротрона ESRF (линии BM26, ID02, ID13)
Экспериментальные кадры in situ SAXS/WAXS, файлы калибровки, фон.
Данные не изменяются агентом; все производные файлы сохраняются отдельно.

## Структура
- data/ — исходные данные (только чтение)
- src/ — скрипты обработки и анализа
- memory/ — заметки и сводки для агента
- paper/ — текст статьи и черновики

## Соглашения
- Язык кода: Python 3.10+, PEP 8.
- Все расчёты воспроизводимы скриптами из src/.
- Промежуточные результаты — в отдельные файлы, не перезаписывать исходные.

## Запреты
- Не коммитить .env, ключи, большие бинарные файлы.
- Не изменять файлы в data/ без явного запроса.
