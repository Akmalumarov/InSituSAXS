## Определение фаз (скрипт `src/zalygin_phases.py`)

### RED — FCC (кубическая гранецентрированная)
- Пики: (111) q=0.5526, (220) q=0.9045, (311) q=1.0570 nm⁻¹
- Отношения: 1 : 1.637 : 1.913 ≈ 1 : √8/√3 : √11/√3 ✓
- Пик (200) при q≈0.638 НЕ виден — там минимум форм-фактора (подтверждено).
- Параметр решётки a = 2π√3/q(111) = **19.69 nm**

### GREEN — гексагональная HII (цилиндры)
- Пики: (10) q=0.6662, (11) q=1.1484, (20) q=1.3257 nm⁻¹
- Отношения: 1 : 1.724 : 1.991 ≈ 1 : √3 : 2 ✓
- Параметр решётки a = 4π/(√3·q(10)) = **10.89 nm**

## Статья Forster 2005 (references/forster_2005.pdf) — ключевые детали

**Название:** "Scattering Curves of Ordered Mesoscopic Materials"
J. Phys. Chem. B 2005, 109, 1347-1360. Авторы: S. Förster et al. (Hamburg, DESY/HASYLAB).

### Основная модель (decoupling approximation)
Интенсивность факторизуется на форм-фактор и структурный фактор:
  I(q) = (b1-b2)² · FN · P(q) · S(q)          (eq 1, 29)
  S(q) = 1 + β(q)·(Z0(q) - 1)·G(q)            (eq 30)
где P(q) — форм-фактор частиц, Z0(q) — решёточный фактор,
G(q) — фактор Дебая-Валлера, β(q) — флуктуационный член.

### Форм-фактор (eq 2-7)
P(q) = F²(L,R,q), факторизуется на продольную и поперечную части:
  F(L,R,q) = F_∥(L,q)·F_⊥(R,q)               (eq 3)
Поперечная амплитуда d-мерной частицы (сфера d=3, цилиндр d=2, ламелла d=1):
  F_⊥(R,q) = ₀F₁[(d+2)/2; -q²R²/4]           (eq 4)
Породовский предел: lim q⁴P(q) = P_∞ (eq 8).

### Решёточный фактор (eq 23)
  Z0(q) = (2π)^(d-1)·c/(n·Vd·Ωd·q^(d-1)) · Σ_{hkl} m_hkl·f_hkl²·L_hkl(q)
m_hkl — мультипликативность, f_hkl — симметрийный фактор (правила погасания).

### Положения рефлексов (Table 4)
- ламеллы (d=1):  q_h = 2πh/a
- гексагональная (d=2):  q_hk = 4π√(h²+hk+k²)/(√3·a)
- квадратная (d=2):  q_hk = 2π√(h²+k²)/a
- кубическая (d=3):  q_hkl = 2π√(h²+k²+l²)/a
- гексагональная (d=3):  q_hkl = 2π√(4/3(h²+hk+k²) + 3/8·l²)/a

### Правила погасания (Table 2)
- FCC (Fm3m): f_hkl = 4 для (h,k,l) все чётные ИЛИ все нечётные.
  → разрешены (111),(200),(220),(311),(222),(400)...
- HEX (P6/mm): f_hkl = 1 для всех рефлексов.

### Фактор Дебая-Валлера (eq 25)
  G(q) = exp[-σa²·aj²·q²]
Подавляет интенсивность высших рефлексов с ростом q.

### КЛЮЧЕВОЙ МЕХАНИЗМ (стр. 9, 11)
"Интенсивности высших рефлексов затухают из-за отклонений от идеальных
положений решётки (фактор Дебая-Валлера) И подавляются на конкретных q
из-за минимумов флуктуационного члена β(q) / форм-фактора."
Для гексагональной лиотропной фазы: "интенсивность заметно подавлена при
q ≈ 0.6 и q ≈ 1.0 nm⁻¹ из-за минимумов форм-фактора" (стр. 11).

### Применение к нашим данным
- **RED (FCC):** пик (200) при q = 2π√4/a = 0.638 nm⁻¹ отсутствует —
  попадает в минимум форм-фактора (проверено по данным: минимум интенсивности).
  Наблюдаются (111)=0.5526, (220)=0.9045, (311)=1.0570 nm⁻¹.
  a = 2π√3/q(111) = 19.69 nm.
- **GREEN (hex):** пики (10)=0.6662, (11)=1.1484, (20)=1.3257 nm⁻¹.
  a = 4π/(√3·q(10)) = 10.89 nm.

### Параметры фита (Table 5) — для справки
Набор параметров: {a, σa, R, σR, D, η} — параметр решётки, смещение,
радиус частицы, полидисперсность, размер домена, форма пика.
Фит — алгоритм Левенберга-Марквардта. Программа: http://www.chemie.uni-hamburg.de/pc/sfoerster/software.html
