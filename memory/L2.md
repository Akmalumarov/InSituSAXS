# L2 — тезисы

1. Выведены аналитические выражения для функций рассеяния упорядоченных мезоструктур (сферы fcc/bcc/hcp/sc, цилиндры hex/sq, ламели) с учётом полидисперсности, беспорядка узлов, размера домена и core/shell-структур (с. 1).
2. Интенсивность описывается decoupling approximation: I(q) = (b1−b2)²FN(〈F²(q)〉 + 〈F(q)〉²[〈Z(q)〉−1]), где Z(q) — решёточный фактор, q = 4π/λ sin(ϑ/2) (с. 2).
3. Форм-фактор факторизуется: F(L,R,q) = Fd∥(L,q)Fd⊥(R,q), поперечная амплитуда Fd⊥(R,q) = ₀F₁[(d+2)/2; q²R²/4] (с. 2).
4. Полидисперсность описывается распределением Шульца–Цимма, усреднения 〈Fd⊥(q)〉, 〈Fd∥(q)〉 выражаются через гипергеометрические функции 2F1, 3F2 (с. 3).
5. Для core/shell частиц профиль плотности φ(r) = r^(−R): R = 0 для гомогенного слоя, R = 2(d−1)/3 для brushes (с. 4).
6. Решёточный фактор Z0(q) = (2π)^(d−1)c/(nVdΩd q^(d−1)) Σ mhkl f²hkl Lhkl(q); параметры и положения пиков qhkl даны для lam, hex, sq, sc, bcc, fcc, hcp (с. 5).
7. Из-за q^(1−d)-сингулярности Z0(q) интенсивность Ĩ(0) расходится для цилиндров (d=2) и сфер (d=3), но не для ламелей (d=1); модель применима при q ≥ 2π/a (с. 8).
8. Для Au@SiO2 (ядро 15 нм, общий диаметр 75 нм) модель даёт 2Rm = 68.2 нм, 2Rc = 13.7 нм, F = 0.30, R = 0.042, σR = 0.030 (с. 9).
9. Для ламеллярных фаз DDAB/D2O (φ=0.04) и AOT/D2O (φ=0.20) η = 0.15 и 0.26 (согласие с Nallet 0.16, 0.25); толщины бислоёв 2.52 и 1.75 нм против 2.46 и 1.60 нм (с. 10).
10. При золь-гель процессе ячейка уменьшается 32.6→25.5→22.3 нм, диаметр пор 8.44→8.30→7.33 нм; удельная поверхность ASiO2 = 83.8 м²/г (с. 11).
