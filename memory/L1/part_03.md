## Решётчатый беспорядок, форма пиков, GISAXS и интегральная интенсивность (с. 6–7)

Для решёток со статическим беспорядком первого рода решёточный фактор Z(q) = Z0(q)G(q) + (1 − G(q)) (с. 6), где G(q) = exp[−σ²a·ja²·q²] — фактор Дебая–Валлера (с. 6); для ламеллярных систем η = 8σ²a — параметр Кайе (с. 6). Форма пика Lhkl(q) (ур. 27) непрерывно меняется от лоренцевой (ν→0) до гауссовой (ν→∞) (с. 6); ширина δ связана с размером домена D = 2π/δ (с. 6). Интенсивность I(q) = (b1−b2)²FN·P(q)·S(q), S(q) = 1 + β(q)(Z0(q)−1)G(q) (с. 6). Уравнение 30 описывает и GISAXS/GISANS тонких плёнок (с. 7). Инвариант Порода Q = 2π²φ(1−φ)(b1−b2)²FN (с. 7); удельная поверхность Asp = SV/((1−φ)Fsp) (с. 7). При q→0: lim Ĩ(q) = kT·χT·FN (с. 7).
