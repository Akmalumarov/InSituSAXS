## Результаты и обсуждение: структура, форм-фактор, core/shell и bcc (с. 8–9)

**Утверждение.** Из-за q^(1-d)-сингулярности решёточного фактора Z0(q) (eq 23) интенсивность Ĩ(0) расходится для цилиндров (d=2) и сфер (d=3), но не для ламелей (d=1) (с. 8). Для q ≥ 2π/a модель (eq 30) хорошо описывает экспериментальные кривые, но не для q < 2π/a (с. 8).

**Метод.** Набор параметров {a, σa, R, σR, D, ν} извлекается из кривых; для core/shell — {Rm, R, F} (с. 8). Фон: Ĩ(q) = Isample − k·Isolvent (eq 41) (с. 8). Фитирование — алгоритм Левенберга–Марквардта (с. 8).

**Результат.** Для Au@SiO2 (ядро 15 нм, общий диаметр 75 нм) модель даёт 2Rm = 68.2 нм, 2Rc = 13.7 нм, F = 0.30, R = 0.042, σR = 0.030 (с. 9). Для bcc PS-PI (Mn = 21.9×10^4 г/моль, 15.4 wt% PI) рефлексы (110), (200), (211) описаны eq 30 не хуже паракристальной теории (с. 9).
