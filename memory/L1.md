# L1 — реферат по частям

Статья: Förster S., Timmann A., Konrad M., Schellbach C., Meyer A.
«Scattering Curves of Ordered Mesoscopic Materials».
The Journal of Physical Chemistry B, 2005, 109, 1347–1360.

## Аналитические выражения для кривых рассеяния упорядоченных мезоскопических материалов (с. 1–2)

Выведены аналитические выражения для функций рассеяния упорядоченных мезоскопических структур и сравнены с экспериментом (с. 1). Рассмотрены сферы (fcc, bcc, hcp, sc), цилиндры (hex, sq) и ламеллярные структуры; учтены распределения размеров частиц, отклонения узлов решётки, размер домена, core/shell-структуры и формы пиков между лоренцевой и гауссовой (с. 1). Метод основан на decoupling approximation: интенсивность I(q) = (b1−b2)²FN(〈F²(q)〉 + 〈F(q)〉²[〈Z(q)〉−1]) (1), где Z(q) — решёточный фактор, q = 4π/λ sin(ϑ/2) (с. 2). Форм-фактор факторизуется: F(L,R,q) = Fd∥(L,q)Fd⊥(R,q) (3); поперечная амплитуда Fd⊥(R,q) = ₀F₁[(d+2)/2; q²R²/4] (4) (с. 2). Модель количественно описывает высокоразрешённые SAXS и SANS кривые лиотропных фаз, core/shell-наночастиц и мезопористых материалов (с. 1).
## Форм-факторы и решёточный фактор упорядоченных мезоструктур (с. 3–5)

Главное утверждение: интенсивность рассеяния упорядоченных мезоструктур описывается форм-фактором P(q) и решёточным фактором Z0(q). Метод: для полидисперсности используется распределение Шульца–Цимма (с. 3), усреднения 〈Fd⊥(q)〉, 〈Fd|(q)〉 выражаются через гипергеометрические функции 2F1, 3F2 (с. 3). Отношение β(q) = 〈Fd(q)〉²/〈Fd²(q)〉 (с. 3) аппроксимируется гауссовым затуханием β(q) ≈ e^(−σR²R²q²) (с. 3). Для core/shell частиц вводится профиль плотности φ(r) = r^(−R) (с. 4); для гомогенного слоя R = 0, для brushes R = 2(d−1)/3 (с. 4). Решёточный фактор Z0(q) = (2π)^(d−1)c/(nVdΩd q^(d−1)) Σ mhkl f²hkl Lhkl(q) (с. 5). Результат: параметры (n, Vd, φ, mhkl, Ωd, ja) и положения пиков qhkl для решёток lam, hex, sq, sc, bcc, fcc, hcp (с. 5).
## Решётчатый беспорядок, форма пиков, GISAXS и интегральная интенсивность (с. 6–7)

Для решёток со статическим беспорядком первого рода решёточный фактор Z(q) = Z0(q)G(q) + (1 − G(q)) (с. 6), где G(q) = exp[−σ²a·ja²·q²] — фактор Дебая–Валлера (с. 6); для ламеллярных систем η = 8σ²a — параметр Кайе (с. 6). Форма пика Lhkl(q) (ур. 27) непрерывно меняется от лоренцевой (ν→0) до гауссовой (ν→∞) (с. 6); ширина δ связана с размером домена D = 2π/δ (с. 6). Интенсивность I(q) = (b1−b2)²FN·P(q)·S(q), S(q) = 1 + β(q)(Z0(q)−1)G(q) (с. 6). Уравнение 30 описывает и GISAXS/GISANS тонких плёнок (с. 7). Инвариант Порода Q = 2π²φ(1−φ)(b1−b2)²FN (с. 7); удельная поверхность Asp = SV/((1−φ)Fsp) (с. 7). При q→0: lim Ĩ(q) = kT·χT·FN (с. 7).
## Результаты и обсуждение: структура, форм-фактор, core/shell и bcc (с. 8–9)

**Утверждение.** Из-за q^(1-d)-сингулярности решёточного фактора Z0(q) (eq 23) интенсивность Ĩ(0) расходится для цилиндров (d=2) и сфер (d=3), но не для ламелей (d=1) (с. 8). Для q ≥ 2π/a модель (eq 30) хорошо описывает экспериментальные кривые, но не для q < 2π/a (с. 8).

**Метод.** Набор параметров {a, σa, R, σR, D, ν} извлекается из кривых; для core/shell — {Rm, R, F} (с. 8). Фон: Ĩ(q) = Isample − k·Isolvent (eq 41) (с. 8). Фитирование — алгоритм Левенберга–Марквардта (с. 8).

**Результат.** Для Au@SiO2 (ядро 15 нм, общий диаметр 75 нм) модель даёт 2Rm = 68.2 нм, 2Rc = 13.7 нм, F = 0.30, R = 0.042, σR = 0.030 (с. 9). Для bcc PS-PI (Mn = 21.9×10^4 г/моль, 15.4 wt% PI) рефлексы (110), (200), (211) описаны eq 30 не хуже паракристальной теории (с. 9).
## Часть 5: Применение модели к упорядоченным мезоструктурам (с. 10–11)

**Утверждение.** Единая модель (eq 30) описывает SAXS/SANS-кривые упорядоченных мезоструктур: bcc, гексагональных, ламеллярных и fcc-фаз (с. 10).

**Метод.** Параметры (решетка, постоянная a, радиус ядра Rc, полидисперсность σR, параметр Кейе η, форма пика ν) получены фитированием eq 30 и сверены с паракристаллической и Кейе-моделями (с. 10). Для ламеллярных фаз DDAB/D2O (φ=0.04) и AOT/D2O (φ=0.20) η=0.15 и 0.26, согласуясь с Nallet (0.16, 0.25); толщины бислоёв 2.52 и 1.75 нм против 2.46 и 1.60 нм (с. 10).

**Результат.** Для гексагональной фазы PB-PEO-16 при росте концентрации 5→55% ячейка уменьшается, радиус ядра растёт 6.7→7.3 нм, распределение сужается 10%→7% (с. 11). При золь-гель процессе ячейка уменьшается 32.6→25.5→22.3 нм, диаметр пор 8.44→8.30→7.33 нм; удельная поверхность ASiO2=83.8 м²/г (с. 11).
## Выводы и приложение: гипергеометрические функции (с. 12–13)

Метод даёт аналитические выражения для кривых рассеяния сфер, цилиндров и ламелей на разных решётках, позволяя количественно фитировать SAXS/SANS липидных и блок-сополимерных жидкокристаллических фаз, суперструктур core/shell наночастиц и мезопористых материалов (с. 12). Для сфер в кубических решётках описание сравнимо с паракристаллической моделью, для ламелей — с моделью Caillé (с. 12). Пример: тонкая плёнка PS-PI даёт междоменное расстояние 168 nm и радиусы доменов 65.6; толстая — 48.3 nm (с. 12). Все амплитуды 〈Fd⊥(q)〉 и 〈F²d⊥(q)〉 выражаются через гипергеометрическую функцию 1F2[a1,b1,b2;x] (с. 13). Пиковая функция L(q) (eq 27) связана с гамма-функцией Γ[z]; при ν<0.001 она практически лоренциан, при ν>1000 — гауссиан (с. 13).
