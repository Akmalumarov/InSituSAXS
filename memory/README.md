# memory/ — знания проекта

Здесь хранятся рабочие заметки, методики и особенности данных,
которые агент использует при задачах. Это не чужие PDF, а наши
собственные выжимки и правила.

## Структура
- `methods/` — методики обработки Scattering-данных (редукция, фон, трансмиссия и т.д.)
- `stations/` — особенности станций ESRF (BM26, ID02, ID13)
- `notes/` — свободные заметки, идеи, наблюдения

## Как пользоваться
- При задачах по методике — сначала читать соответствующий файл в `methods/`.
- При работе со станцией — смотреть `stations/<станция>.md`.
- Обновлять по мере накопления опыта. Старые записи не удалять.
