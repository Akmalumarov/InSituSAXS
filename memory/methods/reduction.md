# Обработка данных — кратко

## Основное правило
Нормировать на трансмиссию Tr **перед** построением графиков и анализом.
Фон вычитается **только по явному запросу** пользователя.

## Обозначения
- `Tr` — трансмиссия (transmission).
- `T` — температура (не путать).

## Последовательность

1. **Загрузить кадр** (EDF, HDF5 — по станции).
2. **Нормировать на трансмиссию:**
   - BM26: Tr ≈ Photo / Monitor (из заголовка EDF).
   - Если Tr нет в заголовке — запросить у пользователя.
   - I_norm(q) = I(q) / Tr.
   - Толщина t, как правило, неизвестна — **не нормировать на t**.
3. **Построить график I_norm(q)**.
4. **Фон** — только если пользователь явно просит:
   - I_corr(q) = I_norm(q) − α · I_bg_norm(q).
   - α подбирается по области больших q, где нет сигнала от частиц.
   - Проверка: I_corr(q) не уходит систематически в минус.

## Проверка
- Tr в диапазоне 0 < Tr < 1, стабильна по серии.
- После вычитания фона: точки не систематически ниже нуля.

## Запрещено
- Вычитать фон без запроса.
- Нормировать на толщину t (её нет).
- Менять формат или имена исходных файлов.
