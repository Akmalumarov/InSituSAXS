# Форм-фактор длинного цилиндра (infinite cylinder)

## Ключевая формула
Ориентационно-усреднённый форм-фактор бесконечного цилиндра (L >> R):

    P(q) ∝ [2 J1(qR)/(qR)]^2 / q

Фактор **1/q** — от усреднения по углу между осью цилиндра и q.
Без него асимптотика была бы q^-3, правильная — q^-4.

## Первый минимум
Первый минимум [2J1(qR)/(qR)]^2 при qR = 3.832 (первый ноль J1).
Для сферы первый минимум f(qR) при qR = 4.493.
При оценке начального радиуса по первому минимуму использовать
соответствующую константу (3.832 для цилиндра, 4.493 для сферы).

## Полидисперсность
Gaussian-полидисперсность радиуса (pd = sigma/R0) сглаживает минимумы.
Усреднение: <P(q)> = ∫ P(q,R) w(R) dR / ∫ w(R) dR, w — гауссово.

## Единицы
SasView выдаёт q в Å^-1. Внутри кода q в нм^-1: q_nm = q_ang * 10.
