# BM26 (DUBBLE, ESRF)

## Формат данных
- EDF (2D-кадры).
- Заголовок — текстовый, поля вида `Key = Value ;`.

## Трансмиссия — ключевые поля
- `Monitor` — падающий поток (ion chamber 1, до образца).
- `Photo` — прошедший поток (ion chamber 2, после образца).
- **Tr = Photo / Monitor.**
- Толщина образца t, как правило, **неизвестна** — не нормировать на t.

## Температура
- `Tlinkam` — температура контроллера Linkam, °C.
- `Euro_PV` — второй температурный канал (Eurotherm), °C.
- Обозначение: `T` для температуры, `Tr` для трансмиссии.

## Время и условия
- `count_time`, `FrameTime` — время экспозиции, сек.
- `time` — дата и время кадра.

## Проверка
- Tr в диапазоне 0 < Tr < 1. (иногда нарушается, сообщать пользователю и ждать дальнейших указаний)
- Monitor и Photo не равны нулю.
- Нет overflow в Monitor / Photo.
