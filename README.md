# InSituXRay

## Цель проекта
Разработать воспроизводимый пайплайн для обработки и анализа данных in situ SAXS/WAXS: загрузка кадров, калибровка, вычитание фона, приведение к
абсолютным единицам, построение кривых I(q) и их эволюции во времени.
Автоматизация обработки синхротронных данных с ESRF. 

## Данные BM26 & ID02
Экспериментальные кадры in situ SAXS/WAXS, файлы калибровки, фон.
Данные не изменяются агентом; производные файлы сохраняются отдельно.
