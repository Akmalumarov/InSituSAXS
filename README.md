# InSituSAXS

Обработка и анализ данных in situ SAXS/WAXS для полимерных материалов.
Лаборатория инженерного материаловедения МГУ имени М.В. Ломоносова.

## О проекте

Пайплайн для обработки синхротронных данных малоуглового и широкоуглового
рентгеновского рассеяния (SAXS/WAXS), полученных в режиме in situ. Цель —
воспроизводимая цепочка от сырых кадров до кривых I(q) и их эволюции во
времени: калибровка, вычитание фона, нормировка, интегрирование
и построение графиков для серии полимерных образцов.

Данные получены на станциях ESRF:
- **BM26** (DUBBLE) — SAXS/WAXS
- **ID02** — высокое разрешение SAXS
- **ID13** — микрофокус, сканирующая дифракция, нанокалориметр

## Данные

| Станция | Формат | Что содержит |
|---|---|---|
| BM26 | ... | SAXS/WAXS-кадры, калибровка, фон |
| ID02 | ... | SAXS-кадры высокого разрешения |
| ID13 | ... | сканы, карты дифракции |

- Исходные данные **не изменяются** и **не коммитятся** (см. `.gitignore`).
- Крупные бинарные файлы хранятся локально или на лабораторном сервере.
- Пути к данным задаются в конфиге, а не хардкодятся в скриптах.

## Обработка

Типовая цепочка (уточняется по мере развития проекта):

1. Загрузка кадра, проверка метаданных.
2. Калибровка (AgBeh / LaB6 / стандарт станции).
3. Маскирование «мёртвых» пикселей и пучкового стопа.
4. Вычитание фона (пустая ячейка / растворитель).
5. Нормировка на ток / время экспозиции / толщину.
6. Интегрирование в I(q) (pyFAI, FIT2D, DAWN — по обстоятельствам).
7. Приведение к абсолютным единицам (по стандарту).
8. Построение эволюции I(q, t) и выделение пиков/областей.
9. Экспорт графиков и таблиц в `memory/` или `paper/`.

## Установка окружения

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Зависимости (черновой список, дополняется):
`numpy`, `scipy`, `matplotlib`, `pyFAI`, `fabio`, `h5py`, `pandas`.

## Как запускать

```bash
python src/<скрипт>.py --config configs/<конфиг>.yaml
```

Единый входной скрипт (когда появится):
```bash
python src/process_series.py --station bm26 --sample <id>
```

## Воспроизводимость

- Каждый результат в `diary.md` снабжается **точкой проверки** — способом
  убедиться в корректности независимо от того, кто/что его получил.
- Скрипты детерминированы; случайные зёрна фиксируются.
- Конфиги и версии библиотек фиксируются.

## Работа с ИИ-агентом

Проект использует агент [AI4Science](https://github.com/andkhalov/AI4Science).
Правила взаимодействия — в `AGENT.md`. Журнал задач и проверок — в `diary.md`.

Агент запускается **из папки проекта**:
```bash
ai4science --mode approve
```
