- `data/` — Экспериментальные и синтетические данные.
- `data/README.md` — описание данных: столбцы, единицы, известные дефекты.
- `src/` - Python-скрипты и модули для анализа данных. Методом будем называть группу скриптов для одной общей крупной задачи.
- `notebooks/` - Jupyter-ноутбуки исследователя. Агент может читать их, но не изменять без явного запроса.
- `results/` - Результаты обработки (тексты, графики, таблицы, новые кривые). Разбиты по образцам.
- `paper/` - Статьи / методички / руководства. Читать только в случае явного запроса.
- `memory/` - Заметки по методам обработки / видам станций и образцов. Cжатие основной статьи проекта — `memory/L2.md`.
- `diary.md` - Журнал работы агента. Заполняется после каждой завершенной задачи.
- `tasks/` - папка с задачами для ИИ-агента. Исследователь ставит задачу либо через терминал либо просит посмотреть конкретный файл в tasks. 
- `checks` — проверки скриптов, формул. Не читать.
