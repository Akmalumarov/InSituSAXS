# ID02 (ESRF)

## Формат
- HDF5 (основной), есть конвертация в EDF
- Типы файлов:
    - `*.h5` — сырые данные; (обычно RAW DATA)
    - `*_ave.h5` — проинтегрированные I(q), q в нм⁻¹; (обычно PROCESSED DATA)
    - `*_azim.h5` — азимутальные профили I(q, χ); (обычно PROCESSED DATA)
    - `*_norm.h5` — 2D I(q), переведённые из пикселей в qx, qy. (обычно PROCESSED DATA)

## Онлайн-обработка
- Данные **автоматически корректируются онлайн** при сборе (программа SPD)
- Выходные единицы: число рассеянных фотонов / телесный угол / падающий фотон

## Нормировка
- Онлайн-обработка **уже включает нормировку на трансмиссию Tr**
- Выход уже поделён на падающий поток, пользователю остаётся
  разделить на толщину образца для абсолютного сечения

## Справочные параметры
- Типичные дистанции SAXS: 1.5 м или 3 м или 9м
- Длина волны: ~0.1 нм (12.46 кэВ)
